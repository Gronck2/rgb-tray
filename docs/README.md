# docs

Besides the user guides (`profiles.md`, `usb-capture.md`, their Russian versions, `examples/`, `screenshots/`),
this folder holds the working docs of the `dev-pipeline` plugin:

- `tasks/`: what to do and why, one file per task (`NNNN-slug.md`). The owner's own task list stays `ROADMAP.md`.
- `plan/`: the approach for a task, written before implementing it; shares the task's `NNNN` number.
- `adr/`: architecture decisions. Immutable once accepted; a later ADR supersedes an earlier one.
- `arch/`: the current shape of the app (`overview.md`), kept up to date when it changes.
