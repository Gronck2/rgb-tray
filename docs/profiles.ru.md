# Профили устройств

[English](profiles.md) · **Русский**

Профиль описывает модель устройства с протоколом, который RGB Tray уже знает, в небольшом файле TOML. Компилировать ничего не нужно: положите файл в `%APPDATA%\rgbtray\devices\` и перезапустите RGB Tray (значок в трее → Выход, потом запустите снова).

Встроенные профили лежат в [`profiles/`](../profiles) в репозитории. Ваш файл с тем же `key` заменяет встроенный, так что модель можно поправить, не дожидаясь релиза. Если ваш профиль работает, пришлите его pull request'ом или приложите к запросу устройства — он станет встроенным для всех.

Если в файле ошибка, RGB Tray его пропускает и пишет причину в отчёте об устройствах (значок в трее → Отчёт об устройствах…, строка «Device profiles») и в `%APPDATA%\rgbtray\rgbtray.log`.

Протоколы, которые сейчас поддерживают профили: **Razer**. Профили для Logitech HID++, ASUS Aura и QMK/VIA в планах.

## Пример

```toml
# Razer Naga V2 Pro: беспроводная (донгл HyperSpeed) и по кабелю.
key = "naga"
name = "Razer Naga V2 Pro"
class = "mouse"
tested = true

[[zones]]
led = 0x04
name = "Logo"
name_ru = "Логотип"

[[zones]]
led = 0x05
name = "Side panel"
name_ru = "Боковая панель"

[razer]
pids = [0x00A8, 0x00A7]
transaction_id = 0x1F
leds = [0x01, 0x04, 0x05]
battery = true
```

## Поля

| Поле | Обязательное | Что это |
|---|---|---|
| `key` | да | Короткий id модели: маленькие латинские буквы и цифры. Id устройств имеют вид `<key>-<серийный номер>`, по ним хранятся настройки. **Не меняйте его потом**, иначе устройство потеряет настройки. |
| `name` | да | Название в панели, по-английски. |
| `name_ru` | нет | Название по-русски, если отличается. |
| `class` | да | `keyboard`, `mouse` или `other`. Выбирает значок и подписи («Вся мышь»). |
| `icon` | нет | `keyboard`, `mouse`, `dock`, `laptop`, `macropad` или `light`. По умолчанию — по `class`. |
| `effects` | нет | Эффекты, которые умеет устройство: из `static`, `breathe`, `cycle`, `off`. По умолчанию все четыре; `off` обязателен. Остальные панель делает бледными. |
| `tested` | нет | `true`, когда модель кто-то проверил на настоящем устройстве. До этого в её карточке написано «не проверено», чтобы владелец знал, что его отзыв нужен. |
| `[[zones]]` | нет | Части, которые панель красит по отдельности: `led` (номер из раздела протокола), `name`, `name_ru`. Без зон у устройства один цвет. |

Числа можно писать в шестнадцатеричном виде (`0x1F`) или десятичном (`31`).

В одном файле можно описать несколько моделей: каждую — в разделе `[[device]]`, а её таблицы становятся `[[device.zones]]` и `[device.razer]` (см. `profiles/razer-mice.toml`).

## `[razer]`: мыши, клавиатуры и аксессуары Razer

Большинство устройств Razer работают через 90-байтный управляющий отчёт, описанный в [OpenRazer](https://github.com/openrazer/openrazer). Значения для модели можно взять из исходников OpenRazer (`driver/razer*_driver.h` — product id, `razer*_driver.c` — transaction id и номера светодиодов).

| Поле | Обязательное | Что это |
|---|---|---|
| `pids` | да | USB product id (vendor 1532). У беспроводного устройства обычно два: донгл и кабель. Id вашего устройства видны в отчёте об устройствах. |
| `transaction_id` | да | Transaction id отчёта: `0x1F` у большинства новых устройств, `0xFF` у старых и многих аксессуаров; у некоторых другие значения (см. OpenRazer). |
| `leds` | да | Номера светодиодов, которые загораются, когда всему устройству дают один цвет, как их называет OpenRazer: `0x00` — единственный светодиод простых устройств, `0x01` — колесо, `0x04` — логотип, `0x05` — подсветка (у Naga — боковая панель), `0x10`/`0x11` — правая/левая боковые полосы. Номера, которых у устройства нет, пропускаются. |
| `battery` | нет | `true`, если устройство сообщает заряд (беспроводные мыши). |

В отчёте Razer нет скорости эффектов, поэтому ползунка скорости у таких устройств в панели нет.
