## Этап 2. Устройства как дополнения

- [x] **Динамический список устройств** (v0.4.0): показываются найденные и «Нет связи»; отключённые — в сворачиваемом архиве «Отключённые устройства» с кнопкой «Забыть»; настройки сохраняются.
- [ ] **Возможности устройства** (эффекты, зоны, цвета клавиш, батарея) задаются драйвером, и панель подстраивается под них сама.
- [ ] **Профили устройств в TOML** (`devices/*.toml`): новая модель известного протокола добавляется без программирования.
  - Протокол `razer`: PID, transaction id, зоны (id, название), батарея.
  - Протокол `logitech-hidpp`: эффекты и цвета клавиш определяются автоматически, в профиле раскладка.
  - Протокол `asus-aura`: ноутбуки ASUS.
  - Перевести текущие устройства (G915 TKL, Naga V2 Pro, Mouse Dock Pro, ASUS) на профили.
- [ ] **Интерфейс драйвера на Rust** для новых протоколов: подробные комментарии, шаблон-пример, регистрация в одном месте.
- [ ] **Раскладки клавиатур в данных** (TKL, полноразмерная, ANSI/ISO), а не в коде.
- [x] **Несколько одинаковых устройств** (v0.4.0): id по серийному номеру (G915 — unit id HID++ 0x0003, Razer — 00:82, MacroPad — по USB-порту), свои настройки и цвета клавиш, переименование карандашом у названия (v0.4.1). Проверить со второй такой же клавиатурой.
- [x] **Диагностика** `rgbtray --diagnose` (v0.5.12): список HID-устройств и интерфейсов для прикладывания к запросу «добавьте моё устройство».
- [ ] *(позже, по спросу)* Скриптовые плагины (Lua/Rhai) без компиляции.
