## LampArray (11.10.2026)

Стандарт HID LampArray (страница 0x59) — подсветка «Динамического освещения» Windows: устройство само сообщает число ламп, их место, назначение и клавиши. Принято: свой драйвер устройства в приоритете, LampArray — для устройств без своего драйвера и как источник дополнительных зон.

- [x] Чтение LampArray по описанию отчётов (номера отчётов не зашиты), сведения в `--diagnose`, тест `rgbtray --lamparray-test <файл> <rrggbb> <секунды>`.
- [x] ASUS (0B05:19B6): 8 ламп — 4 зоны клавиатуры (слева направо) и 4 акцентные лампы по углам нижнего края корпуса; проверено на железе (11.10.2026): все шаги теста видны; 4 лампы корпуса горят каждая своим цветом (яркость у них разная). Первая команда сразу после взятия управления теряется — после `AutonomousMode = 0` нужна пауза (~1 с).
- [x] Подсказка «Включено динамическое освещение Windows» (v0.6.2) (`HKCU\Software\Microsoft\Lighting\AmbientLightingEnabled`, также по устройствам в `Devices\*`) с кнопкой «Открыть параметры» (`ms-settings:personalization-lighting`).
- [ ] Универсальный драйвер LampArray для устройств без своего драйвера: статичный цвет, выкл., яркость; дыхание и спектр — анимацией из приложения. Виртуальные устройства служб производителей (`HID_DEVICE_SYSTEM_VHF`) пропускать.
- [ ] Цвета клавиш для LampArray-клавиатур по кодам клавиш из устройства (InputBinding).
- [ ] ASUS: одноцветные режимы и аппаратные эффекты через Aura, как сейчас; зоны (4 зоны клавиатуры + акцентные лампы) — через LampArray, как зоны Naga.

## Этап 2. Устройства как дополнения

Как пользователи добавляют свои устройства, от простого к сложному:
1. Ничего не делать: устройство со стандартом LampArray работает через универсальный драйвер.
2. «Запросить поддержку устройства…» в меню: отчёт + форма на GitHub (v0.6.1); устройство добавляем мы, пользователь проверяет тестовые сборки.
3. Файл профиля в `%APPDATA%\rgbtray\devices\*.toml` для известного протокола (Razer, QMK/VIA, Logitech HID++, ASUS Aura): без компиляции; удачные профили входят во встроенный список.
4. Свой драйвер на Rust для нового протокола: шаблон, CONTRIBUTING, PR, проверка CI.
5. Закрытый протокол: инструкция, как записать обмен фирменной программы с устройством (Wireshark + USBPcap) и приложить к запросу.
6. Позже, по спросу: скриптовые плагины.

Порядок: универсальный LampArray → общий драйвер QMK/VIA и профили Razer → документация для разработчиков.

- [ ] **Общий драйвер QMK/VIA** для любых VIA-клавиатур с подсветкой (интерфейс FF60:0061), а не только MacroPad: каналы подсветки VIA (backlight, rgblight, rgb matrix).
- [ ] **Инструкция по записи USB-обмена** (Wireshark + USBPcap) для закрытых протоколов.

- [x] **Динамический список устройств** (v0.4.0): показываются найденные и «Нет связи»; отключённые — в сворачиваемом архиве «Отключённые устройства» с кнопкой «Забыть»; настройки сохраняются.
- [ ] **Возможности устройства** (эффекты, зоны, цвета клавиш, батарея) задаются драйвером, и панель подстраивается под них сама.
- [ ] **Профили устройств в TOML** (`devices/*.toml`): новая модель известного протокола добавляется без программирования.
  - Протокол `razer`: PID, transaction id, зоны (id, название), батарея; модели можно брать из списка OpenRazer.
  - Протокол `logitech-hidpp`: эффекты и цвета клавиш определяются автоматически, в профиле раскладка.
  - Протокол `asus-aura`: ноутбуки ASUS.
  - Протокол `qmk-via`: VID/PID, канал подсветки.
  - Перевести текущие устройства (G915 TKL, Naga V2 Pro, Mouse Dock Pro, ASUS) на профили.
- [ ] **Интерфейс драйвера на Rust** для новых протоколов: подробные комментарии, шаблон-пример, регистрация в одном месте.
- [ ] **Раскладки клавиатур в данных** (TKL, полноразмерная, ANSI/ISO), а не в коде.
- [x] **Несколько одинаковых устройств** (v0.4.0): id по серийному номеру (G915 — unit id HID++ 0x0003, Razer — 00:82, MacroPad — по USB-порту), свои настройки и цвета клавиш, переименование карандашом у названия (v0.4.1). Проверить со второй такой же клавиатурой.
- [x] **Диагностика** `rgbtray --diagnose` (v0.5.12): список HID-устройств и интерфейсов для прикладывания к запросу «добавьте моё устройство».
- [ ] *(позже, по спросу)* Скриптовые плагины (Lua/Rhai) без компиляции.
